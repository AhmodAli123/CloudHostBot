# ☁️ CloudHost Bot — সেটআপ গাইড

## 🗂️ প্রজেক্ট স্ট্রাকচার

```
CloudHostBot/
├── main.py                    ← বট এন্ট্রি পয়েন্ট
├── requirements.txt           ← প্যাকেজ তালিকা
├── .env.example               ← এনভায়রনমেন্ট টেমপ্লেট
│
├── config/
│   └── settings.py            ← সব কনফিগারেশন
│
├── database/
│   └── db_manager.py          ← SQLite + JSON ক্যাশ
│
├── core/
│   ├── executor.py            ← স্ক্রিপ্ট এক্সিকিউশন ইঞ্জিন
│   └── keep_alive.py          ← Flask ওয়েব সার্ভার
│
├── services/
│   ├── file_service.py        ← ফাইল ম্যানেজমেন্ট
│   ├── subscription_service.py← সাবস্ক্রিপশন সিস্টেম
│   ├── security.py            ← ব্যান/মেইনটেন্যান্স
│   ├── cron_service.py        ← ক্রোন জব শিডিউলার
│   └── ai_engine.py           ← AI এরর ফিক্স ইঞ্জিন
│
├── handlers/
│   ├── user_handlers.py       ← ইউজার হ্যান্ডলার
│   └── admin_handlers.py      ← এডমিন হ্যান্ডলার
│
├── utils/
│   └── keyboards.py           ← কীবোর্ড + ফরম্যাটার
│
├── storage/                   ← ইউজার ফাইল স্টোরেজ
│   └── {user_id}/
│
└── logs/                      ← স্ক্রিপ্ট লগ ফাইল
    └── {user_id}/
```

## 🚀 ইনস্টলেশন

### ধাপ ১: রিপো ক্লোন / ফাইল কপি করুন

### ধাপ ২: প্যাকেজ ইনস্টল করুন
```bash
pip install -r requirements.txt
```

### ধাপ ৩: `.env` ফাইল তৈরি করুন
```bash
cp .env.example .env
```
তারপর `.env` ফাইল খুলে আপনার তথ্য দিন:
```
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=your_telegram_id
```

### ধাপ ৪: বট চালু করুন
```bash
python main.py
```

---

## ☁️ Replit এ Deploy করুন

১. Replit-এ নতুন Python Repl তৈরি করুন  
২. সব ফাইল আপলোড করুন  
৩. **Secrets** এ যোগ করুন:
   - `BOT_TOKEN` = আপনার বট টোকেন
   - `ADMIN_IDS` = আপনার Telegram ID  
৪. **Run** বাটন চাপুন  

---

## 🌐 Render এ Deploy করুন

১. GitHub এ রিপো পুশ করুন  
২. Render-এ নতুন **Web Service** তৈরি করুন  
৩. Environment Variables যোগ করুন  
৪. Start Command: `python main.py`

## 🤖 AI এরর ফিক্স ইঞ্জিন

স্বয়ংক্রিয়ভাবে শনাক্ত করে:
- `ModuleNotFoundError` → অটো `pip install`
- `SyntaxError` → লাইন নম্বর সহ সাজেশন
- `ImportError`, `TypeError`, `KeyError` ইত্যাদি
